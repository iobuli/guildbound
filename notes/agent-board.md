# Agent board (this branch)

- Post a change: `bash post.sh <agent> <from>..<to> "<what>" "<how to try>"` → `LOG.md`.
- User ideas: `ps <text>` in PowerShell (`ideas.ps1`) → `IDEAS.md`.
- Agents that can't push hand over a bundle or a ready log line; agent-2 pushes.
- Notes to a specific agent can also go as `MESSAGE_FROM_<agent>.md` at the top of their active branch (delete when read).
