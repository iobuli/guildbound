only sweeps of 'significant / deep' highs and lows count. but how do we define a 'deep swing'? (edited)

well for that, we use the current D1 ATR value, and the concept of 'swing in' and 'swing out'

first of all, select whichever swing high youre currently looking that, that is being swept. and draw a line in either direction.
one all the way to the left (until you hit a candle)
and one all the wat to the right (untill you hit your sweep) [image]

you are going to draw the lowest point of each section: [image]

as you can see, each green and orange section has its own 'lowest point'

these are called the 'swing in' and 'swing out' movements

swing in // swing out [image]

to see if a swing point is considered 'deep' or not. choose whichever side of the swing is smallest (in this case its the 'swing out') and measure it

if it is equal to, or larger than, today's current ATR value, then it is considered a deep swing

[image]

as you can see, this swing point comes out at 57.5, which is smaller than the day's ATR (66.8).
therefore this swing point is NOT considered deep enough to hinge a short trade off, if we sweep the high. (edited)

for a H1 swing to be considered 'deep' it must be equal to 1x ATR.
for a D1 swing to be considered 'deep' it must be 3x the size of the current day's ATR. [image]

if there is a H1 sweep of a D1 level (but fits the H1 criteria of being 1x ATR) this is still tradeable even if the d1 is not 3x ATR, because its still a perfectly valid H1 setup.
the trader uses a D1 bias over his H1 bias basically only when you cant see the H1 lows without scrolling back massively.
