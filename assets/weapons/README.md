# Sword school meshes

`trunks_sword.glb` derives from `assets/packs/weapons/longsword.glb` (Warrior Pack Swordsman).
`tapion_sword.glb` derives from `assets/packs/weapons/knight_sword.glb` (Warrior Pack Knight).
Original source paths are recorded in `assets/packs/weapons/weapons.report.json`.

`tools/kev/autoanim/unreal/build_sword_styles.py` removes leftover FBX node transforms,
normalizes the blade to the +Y hitbox axis, and adds steel/guard/grip vertex colours.
